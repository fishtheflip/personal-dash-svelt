# Goal Planner

Планировщик задач на SvelteKit с канбан-доской и календарными заметками.

## Возможности

- создание и фильтрация задач;
- перенос карточек между колонками через drag and drop;
- сохранение канбана в Supabase;
- календарь с заметками по выбранным датам;
- поиск и удаление календарных заметок;
- полезные ссылки с категориями;
- Pomodoro-таймер с режимами фокуса, перерыва и встроенной звуковой атмосферой;
- защищённый вход через Supabase Auth;
- интерфейс на Flowbite Svelte;
- импорт целей из Markdown.

## Стек

- SvelteKit 5;
- TypeScript;
- Tailwind CSS 4;
- Flowbite Svelte;
- Lucide Svelte.
- Supabase.

## Запуск

Требуется Node.js 22.

```bash
npm install
cp .env.example .env
npm run dev
```

Перед запуском создайте Supabase-проект по инструкции
[`SUPABASE_SETUP.md`](./SUPABASE_SETUP.md). Приложение будет доступно по адресу:

```text
http://localhost:5173
```

## Проверка

```bash
npm run check
npm run build
```

## Публикация

Проект подготовлен для автоматического деплоя на GitHub Pages. Инструкция:
[`GITHUB_PAGES.md`](./GITHUB_PAGES.md).

## Маршруты

- `/kanban` — канбан-доска;
- `/calendar` — календарь заметок;
- `/links` — полезные ссылки;
- `/pomodoro` — таймер фокус-сессий;
- `/` — перенаправление на канбан.

## Хранение данных

Задачи, пространства, календарные заметки и ссылки хранятся в Supabase.
Таблицы защищены Row Level Security и доступны только авторизованному владельцу.
При первом входе существующие данные из `localStorage` импортируются в пустые
таблицы.

## Markdown

Учебный журнал и путь разработки находятся в
[`svelte-learning.md`](./svelte-learning.md).

Поддерживаемый формат импорта целей:

```md
# DP Testing

- [ ] Проверить авторизацию !high @due(2026-06-10)
- [x] Записать багфиксы !medium
```

## Безопасность

Файлы окружения, API-ключи, credentials и приватные ключи исключены через
`.gitignore`. Во фронтенде используется только публичный Supabase anon key;
`service_role` key нельзя добавлять в проект.
