# Goal Planner

Планировщик задач на SvelteKit с канбан-доской и календарными заметками.

## Возможности

- создание и фильтрация задач;
- перенос карточек между колонками через drag and drop;
- сохранение канбана в `localStorage`;
- календарь с заметками по выбранным датам;
- поиск и удаление календарных заметок;
- интерфейс на Flowbite Svelte;
- импорт целей из Markdown.

## Стек

- SvelteKit 5;
- TypeScript;
- Tailwind CSS 4;
- Flowbite Svelte;
- Lucide Svelte.

## Запуск

Требуется Node.js 22.

```bash
npm install
npm run dev
```

Приложение будет доступно по адресу:

```text
http://localhost:5173
```

## Проверка

```bash
npm run check
npm run build
```

## Маршруты

- `/kanban` — канбан-доска;
- `/calendar` — календарь заметок;
- `/` — перенаправление на канбан.

## Хранение данных

Сейчас задачи и заметки хранятся в `localStorage` браузера. Серверная база
данных пока не подключена.

## Markdown

Учебный журнал и путь разработки находятся в
[`svelte-learning.md`](./svelte-learning.md).

Поддерживаемый формат импорта целей:

```md
# DP Testing

- [ ] Проверить авторизацию !high @due(2026-06-10)
- [x] Записать багфиксы !medium
```

## Безопасность

Файлы окружения, API-ключи, credentials и приватные ключи исключены через
`.gitignore`. Не добавляйте секреты непосредственно в исходный код.
